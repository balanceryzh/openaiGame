# 余烬集结：HD-2D 四段战场

Godot 4.6.3 原生工程，沿用10000×5500逻辑坐标（200×110真实3D世界）。四段版保留前版和原二维工程历史。

## 启动

解压后使用Godot 4.6.3导入project.godot，按F5；也可运行Start_Linux.sh或Start_Windows.bat（须先安装Godot并加入PATH）。Linux原生图形已实测，Windows未实测，不附Windows可执行程序。

WASD/方向键移动，自动攻击；Esc暂停，暂停/胜败时R重开；Tab查看已发现营地状态；升级时1/2/3；M静音，暂停界面调音乐/音效音量，设置保留。

## 第一关四段

1. 残帆人类营地：破帆布军帐、断木栅、旧军队尸骸；4名可招募士兵，2弓手与2剑盾兵。没有额外隐藏救援点。
2. 破阵战场：错落短沟壕、倒毙人类与恶魔。
3. 焦土围城战场：围攻遗迹与另一组战壕；第二、三段只留壕沟，不设栅栏或拒马；木栅仅存在于首尾军营。
4. 恶魔木垒：木栅营寨、营门壕沟与540逻辑像素宽的可通行吊桥、南侧入口增援和20分钟出征军士长。营门壕沟用于吊桥，不是旧版贯穿全图的战场沟壕。

手绘草泥、土路、帆布与木材贴图；立体军帐破口/支架、木栅及吊桥。原角色与刀光精灵、逐帧草旗动画和用户提供的两首音乐保留。

## 营救与战斗

靠近750像素求救范围，残兵才开始真正反抗并承受围攻伤害；未发现的远处残兵不会悄悄全部阵亡。清除指定围攻者后靠近营救，保留剩余HP；已死者不可重救。独立HP、剑盾挡弹、弓箭命中、升级等沿用既有规则。

无人施救窗口由真实交战决定，不是固定倒计时。v10旧版普通测试约22–29秒，当前新增身体避让后不能继续当作本版实测窗口；游荡敌人加入也会改变窗口。玩家可以优先保护危急者，未保证全部同伴生还。

普通波次仍以视野外直接进入为主，约20%机会尝试有限尸源；中段尸源每区域3–5，首尾1–2，不无限补尸。击败敌人短死亡后消失，不原地复活。

## 死灵法师与泥土召唤

恶魔兵和死灵法师均从恶魔营南侧入口出现，沿侧门与有效道路走出，不在主角附近瞬移。全图同时最多两名死灵法师，首次1.5秒开始尝试，后续间隔45秒；会沿途移动、可以被杀。普通恶魔入口每9秒尝试增援。军团待出队列和最终战会抑制常规增援。

法师78HP、2.2秒前摇、420像素范围优先寻找可用骷髅/僵尸尸源。地上身份保持，实际唤醒成功才消费隐藏尸体。无可用尸源时选择安全泥地点，召出24HP泥土怪（最弱普通亡灵48HP的一半），起身1.5秒无接触伤害。泥土精灵11个独立帧：钻土4、移动4、受击2、待机1；无腿泥团，接触攻击复用蠕动姿势，没有另画挥拳动作。

完成召唤冷却9秒，受击中断冷却3秒；已预订尸源失效则本次中断，下次重新选择，不在同次前摇双生。每法师最多6次成功召唤，召唤单位0XP，不产生新尸源。军团法师的召唤体继承波次归属，必须一起清除；击杀法师可以阻断余下召唤。

## 20分钟第一关

游戏时间5、10、15分钟分别从兵营派出24、32、40名军团单位。每波全灭（含待出场和召唤体）发一次三选一升级，并恢复主角与存活队友各20HP，不超过最大生命。未清军团可以重叠，不会因下一波时间到自动消失。

20分钟开始主吊桥3秒下降，之前主桥关闭、侧门可通。桥落地后队长带60名最终军团出营，Boss音乐切入；队长和最终军团全部清除才第一关胜利。只杀队长不足以通关。20分钟不会另发一支普通5分钟军团；最终阶段停止新的普通增援。取消提前进入恶魔营触发Boss。

暂停、行军图和升级选择均冻结游戏时间。场上最多140敌（为队长保留出场空间），普通远端敌休眠池最多256；超额只退休远处普通闲置单位，0奖励且不造尸，营地和军团单位不丢失。军团按0.35秒间隔逐个安全出场，容量不足则等待，待出队列仍计入未清军团。每帧路径搜索预算8次。

以上人数、恢复量、召唤预算及速度是当前可调原型参数，20分钟时序与军团清除目标来自用户要求。普通属性自动路线测试与人为边界测试分开披露，不保证首次玩家通关。

## 素材与分发

完整包包含全部运行资源；新原画与测试日志另附。无损WebP与源PNG解码RGBA一致，未降低角色帧数、贴图分辨率或音轨完整度。若使用分包版本，必须将“主工程”和“环境资源补充”两个ZIP解压到同一目录，合并battlefield_hd2d文件夹后再导入。

附带视频如注明自动路线/定点机制测试，均使用实际引擎和原战斗属性。MovieMaker固定30FPS输出不代表实际运行帧率。临时全景镜头只用于截图，游戏仍使用已确认高位无斜转镜头。

## 消散与尸源接管

敌人受致命伤立即退出AI、碰撞与伤害，奖励只结算一次；随后6张独立绘制灰尘精灵帧，各0.09秒，共0.54秒后清除。亡灵灰色和恶魔暗红共用同一图集着色，不是两套另画动作。友军原倒下表现保留。
预置尸源仅在成功唤醒时同帧隐藏尸体与投影，由同源起身敌精灵接管；中断施法不消耗尸体。已消费尸源不会因敌人死亡或分区返回而恢复，重开恢复初始场景。
本版在v9消散快照上加入20分钟军团规则，旧版保留历史。


## v11 身体避让实验增量

玩家、友军、敌军统一使用空间格近邻软碰撞和预测运动侧滑，地形碰撞半径不变。队友宽处双列、窄处排队；相向单位靠各自右侧绕行。接触攻击采用左右两个可同时攻击的位置，其余敌人分散靠近并轮换，非全军单人排队。普通目标侧槽34.8px，盾兵40px；Boss后方51.5px。普通亡灵近战有效距离35→42px，恶魔35→50px，Boss53px不变；生命、伤害、攻速及前摇不变。

50%目标按实际Sprite3D投影alpha与根节点居中的身体裁切区近似检测累计前景遮挡，排除多数武器/披风突出；这是身体代理区域，未做逐帧人工语义分割。25秒桥口、近身、召唤三种测试中最高分别16.68%、43.27%、43.27%，未观察到超过50%；这不是任意地图/人数/帧姿势的数学保证。起身与泥土怪采用完整alpha检测。视觉特效、尸体地表和血条不计入身体遮挡。

同条件10随机种子、10亡灵20秒围攻，平均损血从v10的34降至19，约减少44.1%。这是站位和轮换带来的实际平衡变化，并非完全保留原围攻强度。C5d候选旧自动路线在4:03阵亡，后已确认并修复固定营地救援距离与新身体间距冲突；最终C5e改为实际残兵身体边缘接触且视线通达才救援，清围条件不变。修后同路线60秒救出4人，新的完整自动局另行记录。独立时序边界测试验证20分钟事件；本版本没有新的正常实玩通关证明。

正常友军跟随四向输入2秒请求410px，实测400–409px；人工80px紧密圈仍能348–384px。关闭友军跟随让其固定不让路时会阻挡玩家。Linux真实键盘密集布置测试中可右移、上移、左绕后向上脱围。桥流20秒同向和对向分别20/24单位通过，4名跟随队友全过；没有声称瞬间穿过敌墙。

主角、盾兵、弓箭手已接入用户确认的12帧走路。主角使用第6帧髋膝连接修复版；两种盟友沿用各自已确认图像。原始停留2/2/2/2/3/3/2/2/2/2/2/2拍，时基24fps，正常周期26/24秒。实际移动速度驱动播放速率，暂停冻结；攻击、受击、格挡、起身、死亡保持既有动作。

## 圣光闪与手柄
Q / 手柄X（左面键）或RB施放圣光闪：主角中心10码内，对骷髅、僵尸造成50伤害，默认10秒冷却。地图既有换算50逻辑像素=1个3D单位，本版本约定1单位=1游戏码，半径500逻辑像素；泥土召唤物、恶魔和Boss不受此技能伤害。
左摇杆/十字键移动，A确认，B返回，Start暂停，View地图。升级选择支持左右导航与A确认，原键鼠保留。无实体手柄连接，输入测试使用Godot合成事件。
本版本图形显示socket不可用，因此尚未完成新的实机画面录制与集成后的目视验收；不能将之前离线动作预览视为本版游戏录屏。

救援边缘使用84×140px接触椭圆，对应角色76×132px身体占位加8px余量；必须与实际存活残兵接近、视线通达、指定围攻者全部被击败。残兵被推离原点不再令救援失效，不隔墙救人，已救不重复加入。
