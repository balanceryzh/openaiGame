# 余烬集结：已确认步态、圣光闪、手柄版本

## 打开方式
两份ZIP一起解压到同一目录，合并同名 battlefield_hd2d 文件夹。使用Godot4.6打开project.godot，F6/F5运行。不要只解压其中一份。旧版工程ZIP保留，可回退。

## 本次变更
- 主角、剑盾兵、弓箭手使用用户确认的12张真实逐帧图，逐帧原文件不改像素。主角第6张包含已确认髋膝连接修复
- 原节奏2/2/2/2/3/3/2/2/2/2/2/2拍、24fps时基。205px/s播放1倍；320px/s播放约1.561倍。暂停冻结；攻击、受击、格挡、起身、死亡保留旧动作
- 圣光闪：主角中心10游戏码（500逻辑像素 / 10个3D单位）内骷髅和僵尸50伤害，含精确边界，默认10秒冷却，可在battle_logic.gd配置
- 泥土召唤构造体、恶魔、死灵法师、Boss不属于圣光闪目标。沿用原命中、击杀、奖励和消散路径；有金白范围轮廓和光波反馈
- 左摇杆（径向死区0.22，保留幅度）/十字键移动；A确认，B返回，Start暂停，View地图；X或RB施放，Q键同效。升级界面左右选择+A确认，原键鼠保留
