# 余烬集结 / Ember Rally

独立 Godot 4.6.3 HD-2D 战场原型。此目录是一个完整项目，不需要修改仓库内其他游戏。

## 运行
1. 安装 Godot 4.6.3 标准版（非 .NET 版亦可）。
2. 在项目管理器导入本目录的 `project.godot`，等待资源导入，再按 F5。
3. 也可在本目录运行 `godot --path .`，或使用 `Start_Linux.sh` / `Start_Windows.bat`（Godot须在PATH）。

采用 Compatibility 渲染。Linux云桌面已实录；Windows与实体手柄未实测。首次导入会自动建立 `.godot/`，不应提交缓存。

## 操作
- WASD / 方向键，或左摇杆 / 十字键移动
- 自动攻击：有活目标进入实际攻击范围才开始，空地移动不会空挥
- Q / 手柄X或RB：圣光闪，10游戏码内亡灵50伤害，10秒冷却
- Esc / Start：暂停；B返回；Tab / View查看行军图
- 升级时1/2/3，或左右选择后A确认；A确认菜单，R重开；M静音

1游戏码 = 1个3D世界单位 = 50逻辑像素。圣光闪作用于骷髅/僵尸类亡灵，不包括恶魔、死灵法师、Boss或泥土构造体。

## 当前修复
同伴跟随在到达目标时减速并使用启动/停止迟滞，避免每几帧来回切走路与待机。主角不再无目标周期性挥剑。36张已确认逐帧图、地图、BGM与波次保持原样。

## 验证及已知限制
- 手柄合成输入67项、圣光闪48项、动作资源14,431项、攻击新增4项通过
- 无目标120帧移动不空挥；范围内普通攻击仍造成原24点伤害
- 旧规则测试13项、旧场景测试3项失败与修复前一致；不能宣称全套测试全通过
- 个别逐帧原画仍有身体/装备轮廓尺寸变化，运行时切换修复不等于所有视觉抖动消失
- 20秒演示是实际Godot渲染、合成输入和测试敌人设置，不是人工全程通关或硬件帧率测试

可运行 `godot --headless --path . --script res://large/qa/test_target_attack.gd`；其余测试在 `large/qa/`。部分测试生成本地JSON报告，应保持不提交。
